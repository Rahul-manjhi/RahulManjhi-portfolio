# Rahul Manjhi - Developer Portfolio Website

This is my personal developer portfolio showcasing my skills, projects, and experience.  
Built with React, TailwindCSS, and Framer Motion for smooth animations and responsive design.  
Includes interactive features like EmailJS contact form and custom developer-style cursor.

---

## 🚀 Features
- Modern dark theme with responsive design
- Smooth animations using Framer Motion
- Interactive Contact Form (EmailJS integration)
- Custom developer cursor icon
- Project showcase section with images, descriptions, and GitHub links
- Resume download option
- Navigation bar with smooth scrolling

---

## 🛠️ Tech Stack
- Frontend: React (JSX), TailwindCSS
- Animations: Framer Motion
- Email Service: EmailJS (Service ID, Template ID, Public Key integration)
- Deployment: GitHub Pages / Netlify / Vercel
- Version Control: Git & GitHub

---

## 📚 Libraries Used
- react → core framework
- tailwindcss → styling
- framer-motion → animations
- react-icons → icons
- emailjs-com → contact form integration

## ⚙️ How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Rahul-manjhi/rahul-portfolio.git

2. Navigate to the project folder:
   cd rahul-portfolio

3. Install dependencies:
   npm install

4. Start the development server:
   npm start

5. Open in browser:
   http://localhost:3000
